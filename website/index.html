What “development target” means

A platform we are building for, with validation still to complete. No specific Windows build is currently labeled ImageForge verified.

Match your servicing engine

Use an appropriate host DISM or select an installed ADK dism.exe in Image tools. Installing the ADK alone does not switch engines automatically.

Keep a clean source

Work on copies. Validate the result in a VM. A successful export or ISO build does not establish that the final image boots or deploys correctly.

Testing evidence and Microsoft references

The first preview passed a user smoke test; its exact Windows version, target image, and operations were not supplied. Preview 0.3 compiled for Windows x64 and passed 62 core checks on Linux. These checks use local fixtures and simulated HTTP responses; they do not run real Microsoft downloads, Windows servicing, ISO creation, or Windows Setup.

Microsoft documents the underlying platform limits: DISM supported platforms, .NET 8 OS requirements, Windows 11 release information, and Windows 10 release information. See the full project compatibility document and Windows validation checklist.
